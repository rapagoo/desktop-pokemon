# Desktop Pokémon

작업표시줄 위에서 포켓몬들이 돌아다니고, 야생 포켓몬과 알아서 싸우며 성장하는
Windows용 방치형 데스크톱 펫.

## 게임 방법

- 1~2분마다 **야생 포켓몬**(도감 #1~493)이 화면 가장자리에서 걸어 들어옵니다.
- 내 포켓몬 하나에게 다가가 **자동으로 턴제 배틀**을 합니다. 타입 상성이 적용됩니다.
- 이기면 **경험치**를 얻고 레벨이 오릅니다. 쓰러진 야생 포켓몬을 **클릭하면 포획**합니다 (파티 최대 6마리).
- 지면 잠시 쓰러져 쉬었다가 회복합니다. 평소에는 HP가 천천히 차고, 자는 동안은 더 빨리 찹니다.
- 등장·승리·레벨 업·패배·포획 때는 화면 오른쪽 아래에 **표정 초상화 대화창**이 뜹니다.
- 레벨과 경험치는 저장되어 다시 켜도 이어집니다.

## 레벨과 진화

- 야생 포켓몬은 **상대할 내 포켓몬 레벨에 맞춰** 나오고, 원작처럼 레벨에 맞는 진화 단계만 나옵니다
  (Lv.5에 리자몽은 안 나옴). 흔한 포켓몬일수록 자주, 전설은 Lv.40부터 아주 드물게.
- **진화** (도감 #1~493, 원작 진화 방법 기준)
  - 레벨 진화: 그 레벨이 되면 (파이리 → 리자드 Lv.16)
  - 진화의 돌: Lv.30이 되면 (피카츄 → 라이츄)
  - 친밀도: **30번 쓰다듬으면** (피츄 → 피카츄). 이브이는 낮(06~18시)엔 에브이, 밤엔 블래키
  - 통신 교환: **다른 PC에서 깨어나면** (학원 ↔ 집. 고우스트 → 팬텀)

## 학원 PC ↔ 집 PC 연동

우클릭 → **저장 위치 → 클라우드 폴더로 바꾸기…** 에서 두 PC가 같이 보는 폴더(Dropbox, OneDrive 등)를 고르면
진행 상황이 이어집니다. 다른 PC에서 실행 중이면 시작할 때 알려 주고, 다른 PC의 최신 기록을 덮어쓰지 않습니다.
2분마다 자동 저장되고, 다른 PC로 옮겨 가면 포켓몬들이 옆에서 걸어 들어오며 교환 진화가 일어납니다.

**자세한 설정 방법: [docs/SYNC.md](docs/SYNC.md)**

## 수업 중에도 안심

- **화면 공유·녹화에 안 찍힙니다.** Zoom·Teams 화면 공유, 녹화, 스크린샷에서 포켓몬이 빠지고 내 화면에만 보입니다
  (Windows 10 2004 이상).
- **전체 화면 앱이 켜지면 자동으로 숨습니다.** 영상·발표·게임 등이 주 모니터를 꽉 채우면 숨었다가, 끝나면 다시 나타납니다.
- 우클릭 메뉴의 **"수업 집중! 5분 숨기기"**로 직접 숨길 수도 있습니다.

## 실행

Python 3 (표준 라이브러리만 사용, 추가 설치 없음)

```
python desktop_pokemon.py
```

또는 `포켓몬 실행.bat` 더블클릭 (콘솔 창 없이 실행).

## 조작법

- **좌클릭**: 쓰다듬기 (자고 있으면 깨어남) / 쓰러진 야생 포켓몬은 포획
- **드래그**: 집어 들기 / 던지기
- **더블클릭** 또는 **Ctrl + Alt + P**: 관리 창 열기
- **우클릭**: 메뉴 — 레벨·HP·타입 보기, 관리 창, 야생 포켓몬 부르기, 재우기, 돌려보내기(확인 후), 5분 숨기기, 종료

## 관리 창

| 탭 | 내용 |
|---|---|
| 파티 | 레벨·HP·경험치·친밀도, 다음 진화 방법. 쓰다듬기 / 재우기 / 보관함으로 |
| 보관함 | 파티(최대 6마리) 밖의 포켓몬. 파티가 가득 찼을 때 잡은 포켓몬도 여기로. 파티로 데려오기 / 놓아주기 |
| 도감 | #1~493 잡음·만남 현황, 칸을 누르면 초상화·타입·진화 정보 |
| 기록 | 포획·진화·레벨 업·도착 기록 (어느 PC에서 있었는지 포함) |
| 설정 | 저장 위치, PC 별명, 전체 화면 자동 숨김, 5분 숨기기, 야생 포켓몬 부르기, 종료 |

관리 창도 화면 공유에 안 찍히고, Esc로 닫습니다. 보관함·도감·기록은 학원 ↔ 집 연동에 같이 이어집니다.

## 스프라이트

스프라이트 이미지는 이 저장소에 포함되어 있지 않습니다. 처음 실행할 때 받아서
`sprites/` 폴더에 캐시합니다.

- **기본**: [PMDCollab/SpriteCollab](https://github.com/PMDCollab/SpriteCollab)의
  포켓몬 불가사의 던전 스타일 스프라이트와 표정 초상화. 걷기 / 대기 / 잠자기 / 공격 / 원거리 공격 /
  피격 / 기절 애니메이션을 상태에 맞게 재생합니다. 1025마리 중 980마리 지원 (#1~493은 전원).
- **포켓몬 데이터**: 이름·타입·종족값·포획률·진화 정보는 [PokeAPI](https://pokeapi.co/)에서 받아
  `pokepet/data/dex.json`으로 정리해 두었습니다 (`tools/build_dex.py`).
- **대체**: PMD 스프라이트가 없는 포켓몬은 5세대 도트 스프라이트를 씁니다.
  1~649번은 [PokeAPI/sprites](https://github.com/PokeAPI/sprites)의 공식 BW 애니메이션,
  650번 이후는 [Pokémon Showdown](https://play.pokemonshowdown.com/sprites/)의
  [Smogon](https://www.smogon.com/) 팬메이드 BW 스타일 스프라이트입니다.

## 개발

코드는 `pokepet/` 패키지에 있습니다 (모듈별 역할은 [CLAUDE.md](CLAUDE.md) 참고).

```
python -m pokepet --debug    # 야생 포켓몬이 몇 초마다 등장, 이벤트를 콘솔에 출력 (저장은 party-debug.json)
python -m unittest           # 로직 테스트
```
