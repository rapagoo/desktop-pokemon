# 학원 PC ↔ 집 PC 연동 방법

두 PC가 **같은 클라우드 폴더**(Dropbox, OneDrive, Google Drive 등)에 저장하게 하면 포켓몬·레벨·친밀도가 이어집니다.
계정이나 서버는 필요 없고, 클라우드 프로그램이 파일을 옮겨 줍니다.

```
학원 PC ──저장──▶  Dropbox/DesktopPokemon/save.json  ◀──저장── 집 PC
                  (클라우드가 두 PC에 자동으로 동기화)
```

## 1. 처음 한 번만: 집 PC 준비

1. **Python 3 설치** — <https://www.python.org/downloads/> 에서 받아 설치합니다.
   설치 화면에서 **"Add python.exe to PATH"** 를 체크하세요. (tkinter는 기본 포함)
2. **클라우드 로그인** — 학원 PC와 **같은 계정**으로 Dropbox(또는 OneDrive)에 로그인하고 동기화가 끝날 때까지 기다립니다.
3. **코드 받기** — 터미널(명령 프롬프트)에서:

   ```
   git clone https://github.com/rapagoo/desktop-pokemon.git
   ```

   git이 없으면 GitHub 페이지의 **Code → Download ZIP** 으로 받아 압축을 풀어도 됩니다.

## 2. 처음 한 번만: 두 PC에서 저장 위치 정하기

**학원 PC에서 먼저**

1. 포켓몬을 **우클릭 → 저장 위치 → 클라우드 폴더로 바꾸기…**
2. Dropbox 폴더(예: `C:\Users\<이름>\Dropbox`)를 고릅니다.
   → 그 안에 `DesktopPokemon` 폴더가 생기고 지금 진행 상황이 저장됩니다.
3. **우클릭 → 저장 위치 → 이 PC 별명** 을 `학원` 으로 바꿉니다. (대화창에 "학원에서 왔어!" 처럼 나옵니다)

**집 PC에서**

1. 받은 폴더의 `포켓몬 실행.bat` 을 실행합니다. (처음엔 기본 포켓몬 3마리로 시작)
2. **우클릭 → 저장 위치 → 클라우드 폴더로 바꾸기…** 에서 **학원 PC와 같은 클라우드 폴더**를 고릅니다.
3. *"그 폴더에 학원에서 저장한 기록이 있어요. 그 기록으로 바꿀까요?"* → **예**
4. **이 PC 별명** 을 `집` 으로 바꿉니다.

이제 학원 포켓몬들이 화면 옆에서 걸어 들어옵니다.

## 3. 그다음부터: 그냥 실행

양쪽 다 `포켓몬 실행.bat` 만 실행하면 마지막 기록에서 이어집니다.

- **끌 때는 우클릭 → 종료** 를 권장합니다. 마지막으로 저장하고 "실행 중" 표시를 지웁니다.
  (2분마다 자동 저장도 되므로, 그냥 PC를 꺼도 최대 2분치만 잃습니다)
- 다른 PC로 옮겨 가면 포켓몬들이 **"학원에서 왔어!"** 하며 옆에서 걸어 들어옵니다.

## 통신 교환 진화

다른 PC에서 저장된 포켓몬이 이 PC에서 깨어나면 **통신 교환**으로 칩니다.
교환으로 진화하는 포켓몬(고우스트 → 팬텀, 근육몬 → 괴력몬, 롱스톤 → 강철톤 등)은 도착하자마자 진화합니다.

> 교환 진화를 노린다면: 학원에서 잡고 → 집에서 켜기.

## 시간대 진화

이브이의 친밀도 진화는 **실제 시각**을 봅니다.

| 시간 | 진화 |
|---|---|
| 낮 06:00~18:00 (학원) | 에브이 |
| 밤 18:00~06:00 (집) | 블래키 |

친밀도는 **쓰다듬기 30번**입니다. 횟수는 저장되어 PC를 옮겨도 이어집니다.

## 문제가 생기면

| 상황 | 원인과 해결 |
|---|---|
| 시작할 때 *"다른 PC에서 실행 중인 것 같아요"* | 다른 PC에서 아직 켜져 있거나, 그 PC를 종료 없이 끈 지 3분이 안 됨. 다른 PC를 끄고 실행하거나, 그대로 실행해도 됩니다 (아래 충돌 방지가 있음). |
| 집에서 켰는데 학원 진행이 안 보임 | 클라우드 동기화가 아직 안 끝났을 수 있습니다. 클라우드 아이콘이 "최신 상태"가 된 뒤 다시 실행하세요. 저장 위치가 클라우드 폴더인지 **우클릭 → 저장 위치** 에서 확인하세요. |
| `DesktopPokemon` 폴더에 `save-conflict-<PC이름>.json` 이 생김 | 두 PC를 동시에 켜서 한쪽이 더 최신 기록을 덮어쓰려 할 때, 덮어쓰지 않고 따로 저장한 파일입니다. 필요하면 그 파일을 `save.json` 으로 이름을 바꿔 그 기록을 쓸 수 있습니다. |
| 클라우드 연동을 그만두고 싶음 | **우클릭 → 저장 위치 → 이 PC에만 저장하기** |

## 어디에 무엇이 저장되나

| 파일 | 위치 | 내용 |
|---|---|---|
| `save.json` | 클라우드 폴더 `DesktopPokemon/` | 파티 (번호·레벨·경험치·HP·친밀도·마지막 PC), PC 별명 |
| `running.json` | 클라우드 폴더 `DesktopPokemon/` | 지금 실행 중인 PC (1분마다 갱신) |
| `settings.json` | 프로젝트 폴더 (PC마다 따로) | 클라우드 폴더 위치, 이 PC 별명 |
| `party.json` | 프로젝트 폴더 | 클라우드를 안 쓸 때의 저장 파일 |
| `sprites/` | 프로젝트 폴더 | 스프라이트·초상화 캐시 (PC마다 처음 실행할 때 받음) |
